# L'oral

VCE French Second Language oral examination practice, as a single web page.
Open it at the address below; on a phone, add it to the home screen and it
works with no signal.

- Section 1 questions, each with follow-ups and the same answer written
  three ways
- The whole examination on the clock, in the order it runs
- Drills built from the VCE French oral assessment reports, 2020 to 2025
- Twenty-one subtopics in four groups, eight of them named in those
  reports as having been brought into the room
- Useful phrases, with the ones assessors quoted marked as such
- Self-marking against the VCAA criteria, quoted word for word

**It is a draft.** The criteria, the room procedure and every drill item
come from a VCAA document or a French assessor report. The French sentences
themselves were written for this app and have not been read by a French
teacher. Argue with all of it.

Nothing is collected. Recordings stay in the browser tab and are gone when
the page closes; ticks and marks stay on the device.

Source and working notes live in a separate private repository.
